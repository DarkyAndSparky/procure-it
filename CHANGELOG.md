# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).
Версии — по внутренней схеме `YYwWWr-bNN` (год-неделя, релиз/билд).

Этот файл — единственный источник истины для истории изменений: раздел
«Последние изменения» на странице «О системе» приложения парсит именно его
(`src/changelog.js`), отдельного дублирующего списка в коде нет.

**Каждый значимый коммит должен добавлять сюда запись.** Pre-commit хук
(`scripts/hooks/pre-commit`, ставится через `npm install` → `prepare`)
напоминает об этом, если меняются файлы в `src/`, `public/js/` или
`public/*.html`, а `CHANGELOG.md` в этом же коммите не тронут.

## [26w31-b01] — 2026-08-13

### Добавлено
- Тип документа определяет префикс номера спецификации (П/Р/М/С) и состав документа
- Поле «Контрагент» в заявке
- Умный импорт позиций из Excel: автоопределение колонок, закупочной цены, суммы доставки
- Настраиваемая папка для автобэкапов + бэкап прикреплённых файлов
- Статус раскладки файлов в сетевую папку — переживает перезапуск сервера
- Страница «О системе»: живое окружение, технологии, зависимости, время последнего бэкапа, проверка устаревших пакетов
- Автотесты (`node --test`) на формулу расчёта цены, генерацию `.docx`, миграцию схемы БД

### Изменено
- Уникальность номера спецификации — в рамках организации, а не глобально
- Округление до 2 знаков во всех расчётах и Excel-формулах
- Единый паттерн имён скачиваемых файлов
- Красная строка в `.docx` через табуляцию вместо `w:ind firstLine` — надёжнее при печати из Word
- Кэш статики: `no-cache` вместо часового `max-age`
- «Конфиг» переименован в «Настройки», реорганизация страницы
- Формула расчёта цены вынесена в общий модуль `pricing-core.js` (устранено дублирование между формой и Excel-экспортом)

### Исправлено
- Сброс версии в сайдбаре после логина/смены пароля
- Опечатка в границах служебных таблиц `.docx` (JS-свойства `insideHorizontal`/`insideVertical`)
- Ширина таблицы спецификации теперь точно совпадает с полями страницы
